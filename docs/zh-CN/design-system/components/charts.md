# Chart

源码：`src/components/Chart/`。一个 React/SVG 组件覆盖 19 种统计图形，共用图例、提示、键盘访问与数据表。没有新增图表运行时依赖，不请求远程数据。类型名称参考 [uCharts 类型清单](https://gitee.com/uCharts)；本组件使用独立 API，不转换 uCharts 配置。

# 类型与数据语义

| 类型 | 数据与行为 |
| --- | --- |
| `column`、`bar` | 分类分组；可选正负值堆叠，在零值两侧分别累计。 |
| `line`、`area` | 分类趋势；`null`/无效值保留缺测断点。可选横向控制点曲线，不越过相邻点的纵坐标范围。 |
| `mount` | 山丘高度表达分类数值，默认尖顶；`smooth` 使用两段三次曲线绘制圆润峰顶，峰顶与山脚均为水平切线。正数、负数和零值均保留原数值高度。 |
| `mix` | 系列可选 `column`、`line` 或 `area`，共用一个数值轴。 |
| `scatter`、`bubble` | 明确传入有限 `x`、`y`；气泡面积与正数 `size` 成正比（默认 1），非正权重不绘制。 |
| `pie`、`ring`、`rose` | 读取首个系列，仅绘制正值。饼/环用角度表达占比；玫瑰图等角分区、平方根半径，用面积表达数值。环形中心显示可见合计。 |
| `radar` | 至少三个分类，共用一个值域。缺测系列只画有效点，不补出虚假的填充多边形。 |
| `arcbar`、`gauge` | 每个可见系列的首个有效点；仪表盘仅读取首个可见系列。默认范围 0–100。图形限制在范围内，提示保留实际数值。 |
| `funnel` | 读取首个系列，阶段宽度表达数值。保留输入顺序，不静默排序。 |
| `word` | 读取首个系列，正值控制字号。确定性避碰布局，窄屏缩小文字；放不下的词仍保留在数据表中，并展示说明。 |
| `candle` | 完整 `open/close/low/high`，开盘与收盘必须在最低和最高之间。上涨蜜桃红，下跌薄荷绿。提示展示四个数值。 |
| `time` | 明确传入毫秒时间戳 `x` 和有限 `y`，按 x 排序并保留真实时间间隔。横轴默认显示本地 `HH:mm`。 |
| `map` | 首个系列按数据点 `name` 与 `regions` 关联。调用方提供平面多边形坐标，纵轴向上；两轴等比缩放，嵌套轮廓使用 evenodd 填充。没有内置地理边界或投影。 |

`null`、非有限数和不完整坐标不绘制，保留分类下标。零值不等于缺测：坐标图和数据表保留零值，但不会将其绘制成有面积的饼图扇区。坐标图和地图支持负数；饼/环/玫瑰/漏斗/词云/雷达不将负数作为占比绘制。

自动数值轴包含零值，选择易读的十进制步长。显式 `min`/`max` 定义范围，越界图形被限制，但提示保留原值。系列名称应唯一；分类标签取自 `categories`、点名称或从 1 开始的序号。数据数组视为不可变数据，更新时替换系列引用。

# 视觉规范

| 部分 | 规范 |
| --- | --- |
| 容器 | 全宽，20px 内边距，20px 圆角，1.5px 浅沙边框，奶油背景，无卡片阴影。480px 以下内边距为 12px。 |
| 配色 | 薄荷 `#19b7a7`、蜜桃 `#e59266`、绿 `#8ac68a`、紫 `#b38ad3`、黄 `#e4b84f`、蓝 `#7e9fc4`、粉 `#dc8c9e`、棕 `#9a835a`。单点色优先于系列色，再取 `colors`。 |
| 文字 | 继承组件库字体。标题 17px/800，坐标 11px/600，数值标签 12px/700，使用大地棕文字。 |
| 环形中心 | 数值使用 24px/900 的次级大地棕，说明使用 12px/600。两行均采用 SVG central 基线与水平居中锚点，文字中心分别位于圆心上方 8px 和下方 16px，作为一个两行文字块视觉居中。等宽数字使合计变化时保持稳定。 |
| 绘图区 | 默认高度 300px，最小 180px。ResizeObserver 跟随容器宽度；画布最小宽度 280px，更窄容器局部横向滚动。 |
| 网格 | 沙色虚线（`3 6`），正负混合时有独立零基线；按可用空间抽稀分类标签。 |
| 图形 | 柱圆角最大 9px，堆叠柱 2px；折线 3px、圆角连接；面积透明度 0.18，气泡 0.55。SVG 表达数据几何，不作为图标系统。 |
| 提示 | 奶油面板，14px 圆角，14px × 16px 内边距，最大宽度 260px，柔和阴影 `0 4px 14px rgba(61,52,40,.16)`。渲染后测量内容，跟随数据位置并考虑横向滚动，限制在可见绘图区内。悬浮面板不拦截点击，锁定后长内容可在面板内滚动。使用色点、对齐的等宽数字和锁定标识区分读数。 |
| 图例 | 可换行的 50px 胶囊，10px 色点，隐藏后弱化并加删除线。坐标/雷达/仪表按系列，饼/环/玫瑰/漏斗/词云/地图按数据项。 |
| 动效与焦点 | 250ms 淡入、200ms 透明度、滤镜与图例悬浮过渡，均使用组件库缓动。薄荷色 2px 焦点框。非关联图形弱化至 0.24 透明度，激活图形增加轻微投影，不改变数据几何。辅助线使用 4 5 虚线，激活坐标点显示 7px 指示圆。减少动态效果设置下禁用动画与过渡。 |

# 交互与无障碍

根节点为 `role="figure"`，绘图区为带名称的分组，数据点具有独立可读名称。Tab 通过单个移动焦点入口进入绘图区，方向键逐项循环浏览，Home/End 到达首尾，Tab 离开并访问后续控件。Enter/Space 和点击触发 `onDataClick`；`selectable` 默认 true，同时切换锁定。锁定后鼠标移动不改变读数；再次点击同一点、解除按钮、空白绘图区或 Escape 解锁，方向键浏览也会解锁。加载、删除或隐藏选中数据、改变其身份都会清理锁定；身份不变的数据更新会刷新读数。

`tooltip` 支持布尔值或配置对象。默认按分类下标对比当前可见系列；时序图按相同时间戳关联，雷达按相同维度关联。散点、气泡与非分类图使用单项提示，缺测不会补零。指针在笛卡尔绘图区内可定位最近分类，在雷达圆形区域内按指针角度定位最近可见维度，零值点同样保留维度归属；均无需精确碰到细小图形；离散坐标使用 24px 邻近范围，小点和零值提供 12px 命中区域。分类图提供一条轴向辅助线，适用的单点坐标图提供双向辅助线。可通过 `trigger: 'item'` 和 `crosshair: false` 调整。

饼、环、玫瑰提示显示相对已绘制合计的占比。漏斗按输入顺序展示相对首个与上一个可见阶段的比例，分母为零时省略对应比例；递增漏斗数值可能超过 100%。`showPercentage: false` 隐藏这些明细。`render` 收到分类、原始数据、格式化数值、颜色、适用比例及锁定状态，返回 null 隐藏面板。`tooltip={false}` 关闭面板与辅助线，`highlight={false}` 关闭视觉高亮，`selectable={false}` 独立关闭锁定。

图例悬浮或聚焦会突出对应系列（包含折线、面积与雷达填充）或数据项。按钮使用 `aria-pressed`，点击隐藏或恢复数据并清理激活读数。全部图例隐藏后仍能访问恢复全部按钮。可展开数据表保留全部有效源数据，包括隐藏项和未放入词云的词。加载使用 `aria-busy` 和状态文案；NoData 分别展示空数据、图例全隐藏与缺少地图轮廓。emptyText 为 React 元素时，整体替换常规空态，避免重复嵌套图标。地图演示为虚构岛屿分区。

# 范围与使用

山峰页在原有图集上方另有独立的尖顶与圆润峰顶对照，采用相同数据、量程与颜色。圆润示例开启 `smooth`，其可复制配置、数据提示和锁定均沿用标准 Chart API。

总览的类型目录使用等宽等高的奶油色入口卡片，内边距和卡片间距均为 24px，最小高度 156px，圆角 20px，搭配浅沙色边框。网格共享行高，说明换行时仍保持全部卡片对齐，文字不截断。目录在容器宽度低于 560px、达到 560px、达到 840px、达到 1200px 时分别使用一、二、三、四列。悬浮时呈现浅薄荷底色并上移 2px，键盘焦点使用组件库薄荷色轮廓；减少动态效果设置下取消位移。

从包根导入 `Chart` 与类型，同时引入常规公共样式。完整声明和用法见 [Chart 技能参考](https://github.com/guokaigdg/animal-island-ui/blob/main/skills/animal-island-ui-style/references/components/charts.md)。演示左侧最下方独立 **图表统计** 分类，包含 **Chart 图表总览** 和 19 个带中英文名称的类型页面。名称与类型对应关系及路由规则见 [图表导航](../demo-site.md#图表导航)。各类型新增独立控制的交互演示，保留之前的演示。

各类型页另有四个独立的样式与场景示例（合计 76 个），总览精选八个示例并提供对应类型页入口。图集默认双列，容器达到 1400px 时四列，低于 720px 时单列；绘图区通常高 240px。变体通过已有公开 API，按各类型适用范围展示配色、单点颜色、分组/堆叠/正负数据、标签、平滑或简洁趋势、量程、单位与不同数据集。所有数据与岛屿轮廓均为虚构。每张图保留独立的图例筛选、提示、锁定与数据明细；可展开的配置代码直接来自实际绘制属性，并包含可独立使用的格式化函数。原有基础、边界和交互演示保留在图集下方。图集仅属于演示站，不新增组件 API 或运行时依赖。

本 API 面向看板规模数据的 SVG 图表，不包含 uCharts 配置兼容、地理投影、缩放拖动、双数值轴、自动聚合或流数据降采样。控制绘制点数，大数据先预处理。`map` 接收已投影的平面轮廓；`radar` 应使用可比较的单位和范围。
